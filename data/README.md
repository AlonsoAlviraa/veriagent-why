# Data: SYNTHETIC and LABELLED

All data is generated by `scripts/make_data.py` (seeded, deterministic; default seed 42). It is not real customer data.
`python scripts/make_data.py` writes `data/snapshot.duckdb` (gitignored, rebuilt on demand) with 5 views:
`v_orders`, `v_returns`, `v_tickets`, `v_logistics`, `v_promotions`. The same SQL runs against these views in SAMPLE_MODE and, later, against the Zetaris views.

Planted scenario `demo_ontime`: a carrier SLA breach (CarrierB, region North) in 2026-10-01..14, plus a trap promotion with matching dates but non-overlapping category/region. Ground truth: `eval/ground_truth.json`, read only by the eval harness. This scenario is the demo and is excluded from the test split.
